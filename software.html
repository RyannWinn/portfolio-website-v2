Takemeter — r/nba Post Classifier

AI201 Applications of AI Engineering

  • A natural language processing text classifier built to categorize Reddit posts from r/nba into four types: analysis, hot_take, reaction, and rumors_news.
  • Contains 221 hand-labeled examples modeled after real r/nba posts and slang from 2019–2025, with 17 flagged edge cases.
  • DistilBERT struggled heavily with the hot_take category, misclassifying 44% of errors as rumor_news. It relied on surface-level cues and didn't detect underlying intent.

Spam Detection Tool

Fairfield University AI Summer Program

  • Implemented a classical SMS/Text Spam Detection Classifier in Python using scikit-learn and classifies incoming text messages as either spam (1) or legitimate (0).
  • Loads a dataset of text messages via pandas and maps the string target labels into binary indicators. It splits the data into training and test sets using train_test_split to evaluate performance on unseen text.
  • Evaluates test-set accuracy and runs inference on custom sample messages. It also trains a Multinomial Naive Bayes classifier, a standard highly efficient probabilistic algorithm.
